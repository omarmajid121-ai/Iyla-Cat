# Dede دي دي

A virtual kitten for children aged 2–5. Dede repeats what you say in a funny voice, eats, drinks, sleeps, takes baths, brushes her teeth, plays, dresses up and visits the doctor. Arabic and English.

## Install on iPad
1. Open **https://omarmajid121-ai.github.io/Iyla-Cat/** in **Safari**.
2. Tap **Share ⬆︎ → Add to Home Screen**.
3. Open Dede from the home screen and allow the **microphone**.

Parents: hold the ⚙︎ button for 2 seconds for language, voice and volume settings.
